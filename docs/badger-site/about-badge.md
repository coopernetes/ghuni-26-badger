## Hardware & specs

###   Compute & storage
 Processor RP2350 dual-core ARM Cortex-M33 @ 200MHz
 Memory 512kB SRAM
 Storage 16MB QSPI XiP flash
 Uses Runs MonaOS and MicroPython apps, with local storage for firmware, apps, and assets.

###   Display & interaction
 Screen 320x240 full-color IPS display
 Backlight 4-zone LED backlight
 Buttons Five front-facing buttons
 Motion Accelerometer
 Touch 8 capacitive touch sensors
 Uses Shows app interfaces and supports button, tilt, and touch-controlled interactions.

###   Connectivity
 Wi-Fi 2.4GHz Wi-Fi
 Bluetooth Bluetooth 5
 Infrared IR receiver and transmitter
 Uses Connects network apps, Bluetooth projects, infrared beacons, and remote controls.

###   Power
 Battery 1000mAh rechargeable battery
 Runtime Up to 8 hours
 Monitoring Battery voltage monitoring and charge status
 Uses Supports portable use, charging status, and battery-aware apps.

###   Ports & expansion
 USB-C Charging and programming
 Expansion Qw/ST port for accessories
 Debug SWD port for hardware debugging
 Board controls RESET / BOOTSEL buttons
 Uses Charges the badge, transfers apps, flashes firmware, connects accessories, and supports debugging.

###   Enclosure
 Material Durable polycarbonate case
 Attachment Lanyard fixings
 Uses Protects the display and electronics while providing a wearable attachment point.
